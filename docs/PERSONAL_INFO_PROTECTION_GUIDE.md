# ｢개인정보 보호법｣ 준거 공공 행정 실무 가이드라인 및 자가진단표

## ▣ 1. 목적 및 법적 근거
- 본 가이드라인은 공공기관·보건 행정 실무자가 기안문·행사·예산·민원·데이터 처리 시 AI 도구 및 자동화 스크립트를 활용할 때 ｢개인정보 보호법｣(법률 제19234호) 및 개인정보보호위원회 ｢공공기관 개인정보 보호 표준지침｣을 준수하여 유출 사고를 원천 차단함을 목적으로 함.

---

## ▣ 2. 공무 실무자를 위한 ｢개인정보 보호법｣ 5대 핵심 조항

| 조항 | 핵심 법적 요건 | 실무 적용 및 위반 방지 수칙 |
|:---|:---|:---|
| **제15조 (수집·이용)** | 법령 근거 또는 정보주체 명시적 동의 범위 내 최소 수집·이용 | 필요 최소 항목만 수집하고 목적 달성 시 즉시 파기함. |
| **제18조 (목적 외 이용·제공 제한)** | 수집 목적 초과 제3자 제공·타 용도 이용 금지 | 타 사업·타 부서 명부 임의 공유 및 외부 비인가 AI에 원본 업로드를 금지함. |
| **제23조 (민감정보 처리 제한)** | 건강·질병·장애등급 등 민감정보는 별도 동의·법령 근거 시만 처리 | 건강수치·질병명·복용약물 평문 노출을 금지하고 통계 수치(건수·비율)로 집계함. |
| **제24조 (고유식별정보 처리 제한)** | 주민·외국인등록번호·여권·운전면허번호 법령 근거 시만 제한 처리 | **주민등록번호 원본 AI·일반 기안문 기재 금지** 및 `880101-1******` 마스킹을 강제함. |
| **제26조 (업무위탁 처리 제한)** | 대행사·용역 위탁 시 안전성 확보·재위탁 제한·감독 의무 명시 | 명부 전달 시 암호화·서약서를 징구하고 위탁 종료 즉시 파기확인서를 징구함. |

## ▣ 3. 생성형 AI 도구 활용 업무 처리 5단계 표준 프로세스

| 단계 | 수행 절차 | 핵심 실행 기준 |
|:---:|:---|:---|
| **1단계** | 문서 성격 분류 및 선별 | 정책·서식·기획서는 활용, 참여자 명부·인적사항·계좌는 AI 입력에서 선별 배제함. |
| **2단계** | 로컬 비식별화 사전 점검 | `python scripts/privacy_guard.py --scan <경로>`로 주민번호·연락처·이메일·계좌 포함 여부를 확인함. |
| **3단계** | 안전 마스킹 사본 생성 | `python scripts/privacy_guard.py --sanitize <경로>`로 `[파일명]_sanitized.md` 생성 후 AI에 인입함. |
| **4단계** | AI 협업 및 초안 생성 | 공식 직제명(예: 건강증진과장, 총괄주무관) 위주 및 다단계 개조식 서식으로 빌드함. |
| **5단계** | 최종 결재 전 자가진단 | 아래 10대 체크리스트 점검 완료 후 공문서를 시행함. |

## ▣ 5. 공문서 기안 및 AI 협업 전 10대 자가진단 체크리스트

- 공문서 시행, HWPX 배포 또는 AI 대화창 입력 전 10개 항목을 의무 점검함:
  - [ ] **1. 법적 근거:** 개인정보 수집·이용·조회의 명확한 법령·조례 근거 존재 여부
  - [ ] **2. 고유식별정보 배제:** 주민·외국인등록번호 원본(13자리) 미포함 여부
  - [ ] **3. 민감정보 집계화:** 건강·장애·진료내역의 통계 수치(건수·비율) 처리 여부
  - [ ] **4. 연락처 마스킹:** 행정 직통 유선 외 개인 휴대전화 마스킹(`010-****-1234`) 여부
  - [ ] **5. 계좌 은닉·G2B 하이픈:** 계좌번호 마스킹 및 조달청 10자리 코드 표준 하이픈(`60109399-01`) 표기 여부
  - [ ] **6. 직제명 표기:** 개인 실명 대신 '총괄주무관'·'사업팀장' 등 공식 직제명 기술 여부
  - [ ] **7. 사전 스캔 실행:** `scripts/privacy_guard.py` 스캔 및 마스킹 사본 생성 여부
  - [ ] **8. 원본 파일 격리:** 명부 엑셀·개인정보 DB의 공용/클라우드 동기화 폴더 미방치 여부
  - [ ] **9. 목적 외 사용 금지:** 당초 승인 사업 목적 외 타 업무 전용 차단 여부
  - [ ] **10. 잔류 캐시 파기:** 업무 종료 후 임시 마스킹 파일·출력물 안전 파기 여부

## ▣ 6. 로컬 비식별화 CLI 도구 활용법

```bash
# 1. 개인정보 포함 여부 사전 진단 (원본 무수정)
python scripts/privacy_guard.py --scan "D:/Desktop/사업기획서.md"

# 2. 비식별화 마스킹 사본(_sanitized.md) 즉시 생성
python scripts/privacy_guard.py --sanitize "D:/Desktop/사업기획서.md"

# 3. 한글(.hwpx) 내부 텍스트 직접 스캔 및 마스킹 사본 빌드
python scripts/privacy_guard.py --scan "D:/Desktop/결과보고서.hwpx"
python scripts/privacy_guard.py --sanitize "D:/Desktop/결과보고서.hwpx" --output "결과보고서_안전본.hwpx"
```
