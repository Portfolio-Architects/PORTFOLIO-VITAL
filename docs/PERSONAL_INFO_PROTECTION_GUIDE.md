# ｢개인정보 보호법｣ 준거 공공 행정 실무 가이드라인 및 자가진단표

## 1. 목적 및 법적 근거
본 가이드라인은 공공기관 및 보건 행정 실무자가 일상적인 행정 업무(기안문 작성, 행사 기획, 예산 편성, 민원 처리, 데이터 분석 등)를 수행함에 있어, 인공지능(AI) 도구 및 자동화 스크립트를 활용할 때 ｢개인정보 보호법｣(법률 제19234호) 및 개인정보보호위원회 ｢공공기관 개인정보 보호 표준지침｣을 철저히 준수하여 정보 주체의 권익을 보호하고 유출 사고를 사전에 원천 차단하는 것을 목적으로 함.

## 2. 공무 실무자를 위한 ｢개인정보 보호법｣ 5대 핵심 조항

| 조항 | 핵심 법적 요건 | 실무 적용 및 위반 방지 수칙 |
|:---|:---|:---|
| **제15조 (개인정보의 수집·이용)** | 법률에 특별한 규정이 있거나 법령상 의무 준수를 위해 불가피한 경우, 또는 정보주체의 명시적 동의를 받은 경우에만 수집 가능. 수집 목적 범위 내에서만 이용. | - 사업 및 행사 진행 시 '필요 최소한의 항목'만 수집.<br>- 수집 목적 달성 시 즉시 파기 원칙 적용. |
| **제18조 (개인정보의 목적 외 이용·제공 제한)** | 수집 목적 범위를 초과하여 제3자에게 제공하거나 목적 외 용도로 이용하는 것을 원칙적 금지. | - 특정 사업을 위해 수집된 구민 명부를 타 사업 홍보나 다른 부서에 임의 공유 금지.<br>- AI 학습용이나 외부 비인가 도구에 원본 파일 업로드 금지. |
| **제23조 (민감정보의 처리 제한)** | 사상·신념, 건강, 유전정보, 성생활, 범죄경력 등 민감정보는 정보주체의 별도 분리 동의 또는 법령상 구체적 허용 근거가 있는 경우에 한하여만 처리 가능. | - 건강진단 수치, 질병명, 복용약물, 장애등급 등은 절대 공문서 본문이나 AI 입력창에 평문 노출 금지.<br>- 통계 수치(예: "중증 환자 12명", "대사증후군 위험군 34명")로 집계하여 비식별화 처리. |
| **제24조 (고유식별정보의 처리 제한)** | 주민등록번호, 외국인등록번호, 여권번호, 운전면허번호는 법률·대통령령·국회규칙 등에서 구체적으로 처리를 요구하거나 허용한 경우에만 처리 가능 (주민번호는 동의를 받아도 처리 불가한 것이 원칙). | - **주민등록번호 원본은 어떠한 경우에도 AI 대화창, 프롬프트, 일반 기안문에 기재 금지**.<br>- 생년월일 6자리만 남기고 뒤 7자리는 반드시 `*******` 처리. |
| **제26조 (업무위탁에 따른 개인정보의 처리 제한)** | 외부 용역, 행사 대행사, 시스템 운영사 등에 개인정보 처리를 위탁할 경우 위탁계약서에 안전성 확보 조치, 재위탁 제한, 감독 의무 등을 필수 명시. | - 행사 대행사나 용역업체에 참가자 명부 전달 시 암호화 조치 및 서약서 징구.<br>- 위탁 종료 즉시 파기확인서 징구. |

## 3. 생성형 AI 도구 활용 업무 처리 5단계 표준 프로세스

```
┌────────────────────────────────────────────────────────┐
│ [1단계] 문서 성격 분류 및 입력 대상 선별                 │
│ - 정책/서식/기획서/대본: 활용 권장                     │
│ - 참여자 명부/인적사항/상세 계좌: 활용 금지 (선별 배제)  │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│ [2단계] 로컬 비식별화 정밀 사전 점검                   │
│ - 터미널에서 python scripts/privacy_guard.py --scan    │
│ - 주민번호, 연락처, 이메일, 계좌번호 포함 여부 확인     │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│ [3단계] 안전한 마스킹 사본 생성                        │
│ - python scripts/privacy_guard.py --sanitize           │
│ - [파일명]_sanitized.md 복제본 생성 후 AI에 인입       │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│ [4단계] AI 협업 및 초안 생성                           │
│ - 직제명(예: 건강증진과장, 총괄주무관) 위주 기재       │
│ - 다단계 개조식 서식(1. 가. 1) 등) 기반 기안문 빌드    │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│ [5단계] 최종 결재 전 자가진단 체크리스트 감수          │
│ - 아래 10대 체크리스트 점검 완료 후 공문서 시행        │
└────────────────────────────────────────────────────────┘
```

## 5. 공문서 기안 및 AI 협업 전 10대 자가진단 체크리스트

공문서 시행, HWPX 파일 배포, 또는 AI 대화창에 문서를 입력하기 전 아래 10개 항목을 점검하십시오:

- [ ] **1. 법적 근거 확인**: 본 업무에서 개인정보를 수집·이용·조회할 수 있는 명확한 법률적 근거(조례, 법령 등)가 존재하는가?
- [ ] **2. 고유식별정보 배제**: 주민등록번호, 외국인등록번호 등 고유식별정보의 원본(13자리)이 문서에 포함되어 있지 않은가?
- [ ] **3. 민감정보 집계화**: 건강정보, 장애등급, 진료내역 등 민감정보가 개인별이 아닌 통계 수치(건수, 비율)로만 처리되었는가?
- [ ] **4. 연락처 표준 마스킹**: 실무 담당관의 행정 공용 직통 유선전화번호 외에 개인 휴대전화번호가 마스킹 처리되었는가?
- [ ] **5. 계좌번호 및 금융정보 은닉**: 보조금, 강사료, 포상금 지급 관련 계좌번호 원본이 외부로 유출되지 않도록 마스킹되었는가?
- [ ] **6. 직제명 중심 표기**: 특정 개인의 실명 대신 '총괄주무관', '의전담당관', '사업팀장' 등 공식 직제명으로 기술되었는가?
- [ ] **7. 로컬 비식별화 도구 실행**: AI에 문서를 전달하기 전 `scripts/privacy_guard.py`를 통해 스캔 및 마스킹 사본을 생성하였는가?
- [ ] **8. 원본 파일 격리**: 원본 명부 엑셀이나 개인정보 DB 파일이 바탕화면 공용 폴더나 클라우드 동기화 폴더에 방치되어 있지 않은가?
- [ ] **9. 목적 외 사용 금지**: 수집된 인적사항이 당초 공고되거나 승인된 사업 목적 외의 타 업무에 전용되지 않았는가?
- [ ] **10. 잔류 캐시 및 파기 확인**: 업무 종료 후 불필요한 임시 마스킹 파일이나 출력물이 안전하게 파기 또는 정리되었는가?

## 6. 로컬 비식별화 CLI 도구 활용법

### A. 개인정보 포함 여부 사전 진단 (스캔)
파일 내에 개인정보가 있는지 확인만 하고 파일은 전혀 수정하지 않습니다:
```bash
python scripts/privacy_guard.py --scan "D:/Desktop/공공문서 폴더/2026년/사업기획서.md"
```

### B. 안전한 비식별화 사본 즉시 생성 (마스킹)
원본 파일은 그대로 보존하고, 개인정보가 안전하게 별표 처리된 사본(`_sanitized.md`)을 생성합니다:
```bash
python scripts/privacy_guard.py --sanitize "D:/Desktop/공공문서 폴더/2026년/사업기획서.md"
```

### C. 한글 문서(.hwpx) 직접 스캔 및 마스킹
한글 HWPX 파일 내부 텍스트를 직접 분석하여 마스킹 사본을 빌드합니다:
```bash
python scripts/privacy_guard.py --scan "D:/Desktop/공공문서 폴더/2026년/결과보고서.hwpx"
python scripts/privacy_guard.py --sanitize "D:/Desktop/공공문서 폴더/2026년/결과보고서.hwpx" --output "결과보고서_안전본.hwpx"
```
