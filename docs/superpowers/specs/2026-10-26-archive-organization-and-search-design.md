## 󰏚 1. 추진 배경 및 목적 (Intent & The Why)

- ❍ **업무 연계성 단절 해소**: 보건소 건강증진팀 실무 특성상 단일 사업(양재천 건강 페스티벌, 서울체력장, 아이뛰움, 손목닥터9988 등)에 관련된 기안문(`.hwpx`/`.hwp`), 예산·산출내역(`.xlsx`), 결과보고서(`.pdf`), 현장 사진(`.jpg`/`.png`)이 다수의 파편화된 폴더에 분산되어 있어 윈도우 탐색기 기본 검색만으로는 연관 자료를 한 번에 찾는 데 과도한 시간이 소요됨.

- ❍ **비정형 파일명 한계 극복**: 파일명에 핵심 사업 키워드가 누락된 채 `(붙임2) 결과보고.hwpx`, `(수합) 문의사항_답변.xlsx`, `1. 작성양식.hwpx` 형태로 저장된 문서를 찾기 위해 파일을 일일이 열어보며 추론해야 하는 병목을 해소함.

- ❍ **시각 자료(사진·시안) 탐색성 확보**: 전체 파일(8,664개)의 48.0%(4,158개)를 차지하는 이미지 파일이 `KakaoTalk_20261023_...jpg`, `copy_20261019_...png` 등 타임스탬프·일련번호 위주로 저장되어 있어 촬영 맥락과 소속 사업 기준으로 즉시 식별·열람할 수 있는 시각 탐색 체계가 필요함.

## 󰏚 2. 목표, 비목표 및 금지 사항 (Goals, Non-Goals & Anti-Goals)

### ▢ 핵심 목표 (Goals)

- ❍ **물리적 폴더 구조 표준화 (1단계)**:
  - 최상위 위계를 **`연도별(2018년~2026년) → 핵심 단위사업별`** 구조로 일원화함.
  - 최상위 루트(`F:\_Organized_Archive\.`)에 방치된 낱개 파일 237개와 임시 압축 해제 폴더 30여 개를 생산 연도 및 해당 단위사업 폴더 하위로 전량 분류·이관함.
  - `2026년` 내부의 33개 파편화·중복 폴더를 **9대 핵심 단위사업 폴더**로 통폐합하고, 과거 연도(`2022년`~`2025년`) 내 유사 중복 폴더(예: `아이_뛰움_사업` ↔ `어린이신체활동_아이뛰움`)도 동일 기준으로 정돈함.

- ❍ **본문·표 추론 색인 및 사진 문맥 태깅 (2단계 - 백엔드/CLI)**:
  - `.hwpx`, `.hwp`, `.pdf`, `.xlsx`, `.pptx`, `.txt`, `.md` 파일의 **본문 텍스트·표 내부 항목·시트명**을 추출하여 로컬 색인(`data/ARCHIVE_INDEX.json`)을 생성함.
  - 이미지 파일(`.jpg`, `.png`, `.jpeg`)에 대해 소속 폴더, 파일 수정일·EXIF 촬영일, 동일 폴더 내 행정 문서의 핵심 사업 키워드를 자동 결합하여 **맥락 태그(연도, 단위사업, 자료유형: 현장사진/포스터·시안/로고)**를 부여함.

- ❍ **VITAL 웹 대시보드 내 아카이브 통합 탐색기 탑재 (2단계 - 프론트엔드/API)**:
  - VITAL 웹 앱(`http://localhost:3001`)에서 키워드 입력 시 **파일명 + 본문 스니펫(일치 문장 미리보기) + 연관 사업 클러스터(관련 문서·예산서·사진 묶음)**를 0.1초 내에 조회함.
  - 사진 전용 **고속 썸네일 그리드 뷰어** 및 검색 결과에서의 **[파일 바로 열기] / [폴더 위치 열기]** 원클릭 로컬 실행 브릿지를 제공함.

### ▢ 비목표 (Non-Goals)

- ❍ 외부 클라우드(Cloudflare KV 등)로 `F:\_Organized_Archive` 내 원본 문서나 사진을 업로드하지 않으며, 모든 파일 열람과 색인은 로컬 PC(`localhost:3001` 및 로컬 디스크) 내에서만 동작함.

- ❍ 무거운 외부 벡터 DB 서버(Docker, Milvus, Qdrant 등)나 유료 외부 Vision API 호출을 강제하지 않고, 오프라인 로컬 환경에서 즉시 동작하는 경량 역색인(Inverted Index + BM25/TF-IDF 키워드·동의어 매칭) 및 폴더·문서 문맥 상속 태깅 방식을 기본 채택함.

### ▢ 절대 금지 사항 (Anti-Goals / Failure Conditions)

- ❍ **원본 파일 유실 및 손상 절대 금지**: 물리적 폴더 이동 과정에서 단 1건의 파일 유실이나 덮어쓰기 손상이 발생해서는 안 되며, 동일 파일명 충돌 시 덮어쓰지 않고 해시 비교(동일 파일이면 `_Duplicates` 격리, 내용이 다르면 `_v2` 접미사 부여) 및 전수 이관 로그(`data/ARCHIVE_MIGRATION_LOG.json`)를 기록함.

- ❍ **바탕화면(`D:\Desktop`) 임의 수정 금지 (`AGENTS.md` Rule O)**: 사용자의 명시적 지시 대상인 `F:\_Organized_Archive` 외에 `D:\Desktop` 산하 파일은 절대 이동·삭제·변형하지 않음.

- ❍ **중복 보관소 검색 오염 방지**: `_Duplicates`(78개) 및 `_Legacy_Duplicates`(2,378개) 폴더는 기본 검색 대상에서 자동 제외하여 검색 결과에 중복 파일이 노출되지 않게 함.

### ▢ 4.2 본문·사진·연계사업 통합 색인 및 VITAL 탐색기 규격

- ❍ **색인 스크립트 (`scripts/organize_and_index_archive.py`)**:
  - **폴더 정돈 모듈 (`--organize`)**: 규칙 기반 분류기 + SHA-256 해시 중복 검사 + `data/ARCHIVE_MIGRATION_LOG.json` 기록 및 `--rollback` 원상 복구 지원.
  - **본문 추출 및 색인 모듈 (`--index`)**:
    - `.hwpx`: ZIP 내부 `Contents/section*.xml` 파싱하여 본문·표 텍스트 고속 추출.
    - `.hwp`: OLE2 `PrvText`(미리보기 텍스트 스트림) 및 `BodyText` zlib 압축 해제 텍스트 추출.
    - `.xlsx`: `openpyxl` / XML 파싱으로 시트명 및 셀 텍스트·수치 추출.
    - `.pdf`: `pypdf`/`fitz` 또는 내장 스트림 파서로 텍스트 추출.
    - `.pptx` / `.docx`: XML 파싱으로 슬라이드·본문 텍스트 추출.
    - `.jpg` / `.png` / `.jpeg`: 파일 경로, 상위 폴더 사업명, 동일 폴더 내 문서에서 추출된 핵심 키워드(최대 10개), 촬영/수정 일자, 이미지 유형(현장사진 / 포스터·시안 / 로고·아이콘) 자동 태깅.

- ❍ **VITAL 대시보드 내 아카이브 통합 탐색기 UI 및 로컬 API (에이전트 설계 결정 사항 / Builder's Call)**:
  - **진입 경로 (Builder's Call)**: 좌측 사이드바(`Sidebar.tsx`) 또는 상단 커맨드 팔레트(`Ctrl+K`) 및 워크스페이스(`WorkspaceView.tsx`) 내에 **「아카이브 탐색기 (Archive Explorer)」** 탭을 추가하여 기존 업무 화면에서 즉시 전환할 수 있게 함.
  - **3대 탐색 뷰 기능**:
    1. **본문·추론 통합 검색창**: 검색어 입력 시 파일명 일치뿐 아니라 **본문 내부 일치 문장(하이라이트 스니펫)**과 **추론 연관 키워드(동의어·사업 약칭 매핑, 예: `메디런` ↔ `AI 메디헬스` ↔ `서울체력장`, `행감` ↔ `행정사무감사`)**를 동시에 검색함.
    2. **연계 업무 묶음(Project Cluster) 패널**: 특정 파일을 클릭하면 같은 단위사업 및 인접 시기(±14일 또는 동일 세부주제)의 **기안문(HWPX) + 예산·산출표(XLSX) + 보고서(PDF) + 관련 사진(JPG)**을 우측/하단 연관 자료 카드로 즉시 묶어 표시함.
    3. **사진 썸네일 갤러리 모드**: `사진/시안만 보기` 필터 선택 시 사업별·연도별·유형별(현장사진/포스터) 썸네일 그리드를 렌더링하고 클릭 시 원본 미리보기 모달 및 소속 폴더 내 연관 보고서를 함께 표시함.
  - **로컬 브릿지 API (`/api/archive`)**:
    - `GET /api/archive`: 색인 데이터(`data/ARCHIVE_INDEX.json`) 조회 및 키워드·연도·사업·확장자 필터링 결과 반환.
    - `GET /api/archive/image?path=...`: `F:\_Organized_Archive` 내 이미지 파일을 안전하게 스트리밍(경로 이탈 검증 적용)하여 브라우저 썸네일/미리보기 제공.
    - `POST /api/archive/open`: 선택한 파일을 윈도우 기본 연결 프로그램(`os.startfile` / `explorer.exe`)으로 즉시 열거나 탐색기에서 해당 파일을 하이라이트 선택(`explorer.exe /select,"<path>"`)하여 실행함.
    - `POST /api/archive/reindex`: 신규 파일 추가 시 웹 화면에서 버튼 클릭 한 번으로 색인을 최신화함.
